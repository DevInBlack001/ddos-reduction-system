Monitoring Architecture

The FLOD System operates in transparent bridge/tap mode, capturing raw frames with zero-copy libpcap ring buffers directly from the active interface.

Change the capture interface
Edit --interface in /etc/systemd/system/ddos-stage1.service, then restart the daemon.
